AutoHotkey v2 夜间自动化与按键重映射工具这是一个基于 AutoHotkey v2 开发的轻量级后台自动化脚本。主要用于在夜间自动化关屏节能、降低系统音量，并提供快捷按键重映射与系统操作支持。✨ 核心功能🌙 夜间闲置关屏：在指定的夜间时间段内，若系统闲置时长达到设定阈值，自动关闭显示器电源（物理按键/鼠标移动可随时唤醒）。🔉 夜间自动降音量：夜间时段内定时微降系统音量，避免夜间突发高音量打扰。⌨️ Copilot 键重映射：将 Windows 新版键盘上的 Copilot 键 改键为 右 Ctrl（RControl），恢复经典键盘习惯。⚡ 常用快捷键支持：随时快捷关屏、一键重启/退出脚本。📌 托盘快捷菜单：系统托盘图标右键菜单，支持状态查询与手动操作。🛠️ 环境要求操作系统：Windows 10 / Windows 11运行环境：AutoHotkey v2.0+⚙️ 可调参数配置打开 .ahk 文件顶部，你可以直接修改以下区块参数以适应个人习惯：Code snippet; --- 夜间时间段定义（24小时制 HHmm 格式） ---
NightStartTime := "2030"   ; 夜间开始时间（默认 20:30）
NightEndTime   := "0900"   ; 夜间结束时间（默认 次日 09:00）

; --- 强制关屏参数 ---
IdleTimeoutMs     := 1800000   ; 闲置多久关屏（毫秒，默认 30分钟 = 1800000）
CheckIntervalMs   := 2000      ; 闲置检测频率（毫秒，默认 2秒）

; --- 夜间降音量参数 ---
VolumeCheckIntervalMs := 1800000  ; 降音量检测间隔（毫秒，默认 30分钟）
